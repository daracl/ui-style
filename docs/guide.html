@daracl/ui-style

Daracl UI 프로젝트가 공통으로 쓰는 SCSS 라이브러리입니다. 디자인 토큰, 라이트 / 다크 테마, 믹스인, 함수, 유틸리티를 제공합니다.

개요

가져오기만 해서는 CSS 가 나오지 않음변수 · 함수 · 믹스인을 @use 해도 출력이 없습니다. 출력은 @include 로 명시합니다.
런타임 테마 전환색상은 CSS 변수(--dui-*)로 제공됩니다. data-daracl-theme 속성 또는 OS 설정으로 전환합니다.
단독으로도 표시컴포넌트 CSS 는 light 값을 fallback 으로 갖습니다. dark 는 theme-vars.css 를 로드하면 됩니다.
모든 프로젝트가 같은 값프로젝트 전용 값만 지역 변수(--dg-* 등)로 두고, 나머지는 이 라이브러리의 변수를 씁니다.

설치 · 진입점

yarn add @daracl/ui-style
yarn add -D sass   # SCSS 를 사용하는 경우 (>=1.80)
경로내용
@daracl/ui-style/abstracts토큰 + 변수 + 함수 + 믹스인 + 브레이크포인트 (CSS 출력 없음)
@daracl/ui-style/tokens디자인 토큰만
@daracl/ui-style/themes테마 맵과 테마 출력 믹스인, themed()
@daracl/ui-style/basereset, keyframes, spinner
@daracl/ui-style/utilitiesscrollbar, 유틸리티 클래스
@daracl/ui-style위 전체 (theme-*, base-*, util-* 접두사로 forward)
@daracl/ui-style/style.css테마 변수 + keyframes + 유틸리티 클래스
@daracl/ui-style/theme-vars.css테마 CSS 변수만 (dark 전환에 필요)

빠른 시작

SCSS 에서 쓰기

@use '@daracl/ui-style/abstracts' as style;
@use '@daracl/ui-style/themes' as themes;

.my-panel {
  padding: style.$spacing-md;                    // 12px
  border-radius: style.radius(md);               // 4px
  z-index: style.z(dropdown);                    // 1000

  // 색은 테마 변수로 → var(--dui-border-color, #d9dde3)
  border: 1px solid themes.themed(border-color);
  background: themes.themed(body-bg);
  color: themes.themed(font-color);

  @include style.flex-between;
  @include style.respond-below(md) { display: none; }
}

.my-input  { @include style.form-control; }
.my-button { @include style.form-button; }

CSS 만 쓰기 (SCSS 없이)

import '@daracl/ui-style/theme-vars.css';   // 테마 변수만
// 또는 import '@daracl/ui-style/style.css';   // 변수 + keyframes + 유틸리티 클래스

dark 로 전환

document.documentElement.setAttribute('data-daracl-theme', 'dark');   // 페이지 전체
element.setAttribute('data-daracl-theme', 'dark');                  // 일부 영역만

테마

전환 방법

지원하는 전환 방식은 두 가지입니다.

  • data-daracl-theme="light | dark" 속성 — 요소 단위로 지정할 수 있고, 가장 가까운 조상의 값이 적용됩니다.
  • OS 설정(prefers-color-scheme: dark) — 속성이 없을 때만 따릅니다. style.css / theme-vars.css 에 포함되어 있습니다.
이전 프로젝트에서 쓰던 body.dark, .dark 같은 클래스 방식은 지원하지 않습니다. 오른쪽 아래 버튼으로 이 페이지의 테마를 직접 바꿔 볼 수 있습니다.
현재 테마: auto

hover / selected / active — 배경과 글자색은 항상 쌍으로 씁니다

배경만 바꾸면 다른 테마에서 글자가 읽히지 않을 수 있어, 아래 쌍은 반드시 함께 사용합니다.

hover · 가나다 ABC 123
hover-bg + hover-color
목록 / 셀 hover 바탕 (중립)
hover-accent · 가나다 ABC 123
hover-accent-bg + hover-accent-color
hover 바탕 (파란 강조)
selected · 가나다 ABC 123
selected-bg + selected-color
선택 바탕
active · 가나다 ABC 123
active-bg + active-color
눌림 / 활성 바탕 (페이지네이션 등)
단독 사용 시 주의 dark 값은 theme-vars.css 가 있어야 적용됩니다. 로드하지 않으면 컴포넌트는 light fallback 으로 표시됩니다. 컴포넌트 안에서 --dui-* 를 다시 선언하지 마세요. 요소에 직접 선언한 값이 앱이 :root 에 지정한 값을 덮어씁니다.

컴포넌트 작성 규칙

해야 할 것

  • 공통 색은 themes.themed(키) 로 참조합니다. 앱이 어떤 CSS 를 로드했는지와 무관하게 light 로 표시됩니다.
  • 프로젝트에서만 쓰는 값은 자기 접두사 변수(--dg-*, --drs-* …)로 두고, define-themes($scope, $prefix: …, $themes: …) 로 light / dark 를 출력합니다.
  • 배경과 글자색이 함께 쓰이는 hover / selected / active 는 쌍으로 사용합니다.
  • 입력 요소 · 버튼은 form-control / form-button 믹스인을 씁니다. 테두리는 input-border-color, 패널 / 표는 border-color.
  • 전역 @keyframes 는 프로젝트 접두사를 붙입니다 (keyframes-fade('프로젝트') → 프로젝트-fade-in).
  • z-index 는 토큰을 씁니다 (style.$z-dropdown, style.$z-modal …).

하지 말 것

  • 컴포넌트 루트에서 --dui-* 를 다시 선언 — 앱의 테마 / 커스텀 값을 덮어씁니다.
  • 접두사 없는 변수(--border-color 등) 선언 — 호스트 페이지의 같은 이름과 충돌합니다.
  • helpers, keyframes, define-themes() 를 여러 컴포넌트에서 반복 호출 — 호출할 때마다 CSS 가 출력됩니다. 앱 진입 CSS 에서 한 번만 호출하거나 style.css 를 쓰세요.

개별 영역 / 인스턴스 테마

한 컴포넌트만 다른 테마로 보여야 한다면 그 요소에서 themes.theme($name) 으로 --dui-* 전체를 지정합니다. (ui-grid 의 dg-dark, ui-components 의 data-theme 가 이 방식입니다.)

// 영역 단위 테마: 공통(--dui-*) + 전용(--dg-*) 을 함께 지정
.daracl-grid .dg-layout.dg-dark {
  @include themes.theme(dark);
  @include themes.theme(dark, $prefix: 'dg', $themes: $grid-themes);
}

JS 에서 색을 읽어야 할 때

// 값이 비어 있을 수 있으므로(theme-vars.css 미로드) 반드시 fallback 을 둔다
const c = getComputedStyle(el).getPropertyValue('--dui-bar-positive-bg').trim() || '#77c0fc';

yarn install
yarn build        # dist/style.css, theme-vars.css (+ .min.css) 와 이 가이드(docs/guide.html)
yarn test         # 빌드 + exports 경로, 공개 API, 테마 CSS, load-path, Sass 경고, 가이드 검증
  • npm pack --dry-run 으로 포함 파일을 확인하고 yarn publish --access public 으로 배포합니다. (prepack 에서 빌드가 실행됩니다.)
  • 각 프로젝트는 dependencies 에 "@daracl/ui-style": "^0.0.0" 형태로 추가합니다. 소스 SCSS 를 함께 배포하는 패키지는 사용자가 @daracl/ui-style 을 찾을 수 있어야 하기 때문입니다.
  • 공통 값(색, 간격 등)을 바꾸면 이 패키지를 배포한 뒤, SCSS 값에 영향받는 패키지는 다시 빌드 · 배포해야 반영됩니다. CSS 변수 값(테마 색)은 theme-vars.css 만 갱신하면 됩니다.
